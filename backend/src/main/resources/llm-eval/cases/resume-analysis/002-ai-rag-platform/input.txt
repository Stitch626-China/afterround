项目经历
项目名称：[项目A]（企业级智能知识管理平台）
2025年09月 - 2025年12月
项目描述：面向企业内部知识管理与智能问答场景，基于 RAG 架构搭建私有知识库平台，实现多格式文档解析、向量化、混合检索与流式问答。
技术栈：Spring Boot、MySQL、MyBatis、Redis、Kafka、Elasticsearch、MinIO、Ollama、WebSocket
核心职责：
· 基于 Redis BitMap 管理文件分片状态（1000 个分片仅占 125 字节），结合 MinIO 实现大文件分片上传与断点续传。
· 使用 Kafka 将文件上传与后处理、切片、向量化等异步解耦，配置失败重试与死信队列，并根据堆内存使用率做背压。
· 封装大模型工具调用 Agentic RAG 问答流程，结合历史上下文、知识检索与来源引用；采用混合检索，向量召回 + 关键词 BM25 二段重排，召回候选后按相关度与权限过滤。
· 基于 WebSocket 建立长连接，集成 DeepSeek 等大模型 Stream API 实现流式响应，按“打字机”式逐字生成并输出。

项目名称：[项目B]（代码智能诊断与修复助手）
2026年04月 - 2026年07月
项目描述：面向 Java 多模块代码库的智能诊断与修复助手，结合代码检索、工具调用、任务规划及上下文管理，支持问题分析、代码修改和测试命令执行，辅助完成多步缺陷定位与修复任务。
技术栈：Java 17、React、Function Calling、MCP、JavaScript、Ollama、SQLite
核心职责：
· Agent 执行与工具集成：基于 ReAct + LLM Function Calling，串联代码搜索、文件读写与测试命令执行，通过 ToolRegistry 统一管理内置工具，支持 MCP 外部工具动态发现与注册，依据依赖图辅助定位问题与代码修复。
· 任务规划与协作仲裁：采用 Plan-and-Execute 与 Multi-Agent 两种执行模式，支持基于 DAG 依赖的任务调度，Plan 模式最多 4 个任务并行，通过 Planner、Worker 与 Reviewer 分工完成任务执行与结果审核，审核失败带反馈重试最多 2 次。
· 分层记忆与上下文压缩：支持对话、事实、摘要和工具结果四类记忆，根据模型上下文窗口自动调整 Token 预算，结合短期记忆 FIFO 淘汰与 Map-Reduce 摘要压缩；历史消息与用户轮次边界隔离，避免 ToolCall 与 ToolResult 配对。
· Code RAG 检索：将混合检索封装为 search_code 工具，基于 JavaParser AST 进行分类方法分块，使用本地 Ollama 生成嵌入并写入向量库；融合语义相似度与关键词过滤，通过去重、重复命中奖励与代码类型加权排序，由模型按需调用，辅助定位相关实现。
· 长期记忆保存与检索：支持用户显式保存项目约定与稳定排障经验，结合项目级过滤、Jieba 分词匹配、时间衰减和 TopK 排序，在 Token 预算内召回并注入相关长期记忆。
