主管面，四十多分钟，面试官是技术负责人，风格很直接，一直在追问定位和上限。开头还是自我介绍，我讲了 [公司B] 一年三个月、[系统B]、[系统A]，还有两个 AI 项目。

他问我觉得自己的优势在哪里。我说入职时间短、开发习惯和思维没有受到污染、沟通没问题因为没被批评过、AI 工具熟练、在 [地区A] 现场交付过三个月。

然后问你到底懂一点啥，Java、面向对象、算法这些。我说 Java 开发可以做；LeetCode 算法没有系统做过，比较弱；深度学习有基础；Python Web 没做过。

他问 AI 能不能写一整套系统。我说能做一个 demo，但落地生产没有经验；另一个 Python 项目完全是 AI 写的，语法、类型、调用我有时候看不太明白。

问规划。我说继续走后端，Agent 也是后端；长期在后端，做业务理解、需求讨论、测试。

问用了什么 Agent 框架。我说公司用 Trae，个人用 Codex；Python 原生 Agent 没用框架；Java 侧从 Spring AI Alibaba 换成 AgentScope；多 Agent 改成单 Agent，原因是 token 成本和工具监控。

他问刚毕业跟那些有经验的人有什么区别。我说说实话没什么区别，只能说沟通合作更适应职场；技术方面没有区别。

又问老同事说不要依赖 AI，你怎么看。我说认同要更好地依赖 AI，AI 能力太惊人了。

他举了个例子，说高手加 AI 可以不需要团队，七个人一年不如我三天。我基本认同，还说如果我以后能把控系统设计，我加上 AI 就可以完全实现。

后面说代码不重要，框架原理要清楚。我表示认同。

问有没有设计图、UML 之类的。我说大概带清楚了，承认没有规范 UML 和注释。

问 AI 实现的系统出故障谁接手。我说人做 review、黑盒和白盒测试。

反问环节我问了公司日常是否大量用 AI、AI 是主体还是辅助、AI 支持力度、保密项目怎么用 AI、团队规模。还问了质量对工期的问题：经理给两三天，我有更好的方案但要多一天，怎么办。最后问这是不是最后一次面试，问了面试流程。面试官说团队三十多人一条产线，前后端、运维、测试都有；我说现公司没有测试，运维也是兼职，压力都在后端。
