## 决策（为什么）

- 保留 ASR 口语重复、错字、断句混乱；只清理 U+FFFD 这种编码替换符，因为它不是真实语音内容。
- 真实材料按规范二次脱敏；无法确认公开安全的具体业务领域、项目来源、籍贯一律改为占位符。
- `review-analyze/005~007` 保持 `sourceType = real-notes`：内容是第一人称个人笔记，不是公开面经改写。
- 真实简历在 `sourceType` 中使用 `community-rewrite`：规范枚举暂无 `real-resume`，不改枚举以免影响后续执行器口径。
- 只提交 `cases/`；原始层（真实转写、简历、音频、标注草稿）永不入 git。
