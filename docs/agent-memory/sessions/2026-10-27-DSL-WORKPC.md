# 2026-10-27 DSL-WORKPC

## 目标

解决两台设备开发时 AI 记忆不互通导致的重复分析与冲突问题，把记忆落到可随 GitHub 同步的仓库文件里。

## 改动（文件 → 说明）

- `AGENTS.md` → 新增 AI 协作契约：开工 pull + 读记忆，收工写记忆 + push，冲突与重复工作防线
- `docs/agent-memory/PROGRESS.md` → 新增进度快照、当前状态、下一步、关键决策
- `docs/agent-memory/sessions/` → 新增本文件，作为会话记录起点
- `README.md` → 目录结构与文档索引补充 AI 记忆机制入口

## 决策（为什么）

- 记忆全部放仓库：唯一需要跨设备同步的通道就是 git，避免维护额外同步脚本。
- 每次会话单独一个文件：两台设备即使同一天开发也不冲突，只增不改。
- `PROGRESS.md` 只维护状态三块 + 决策表，防止多设备同时编辑同一大文件。

## 未完成 / 下一步

- 进入 M1 工程骨架搭建。
